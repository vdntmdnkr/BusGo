EXPERIMENT / ASSIGNMENT: CLIENT-SIDE VALIDATION USING REACTJS
Project: BusGo Booking & Validation Application
================================================================================

1. AIM & OBJECTIVE
To design, develop, and deploy an interactive web application to demonstrate real-time client-side form validation using ReactJS.

2. DESIGN: VALIDATION RULES & CONSTRAINTS
• Full Name: Required, letters & spaces only (3–40 chars). Regex: /^[A-Za-z\s]{3,40}$/
• Email Address: Required, standard RFC 5322 regex: /^[^\s@]+@[^\s@]+\.[^\s@]+$/
• Mobile Number: Country-aware regex (India +91: 10 digits starting 6–9: /^[6-9]\d{9}$/)
• Age: Numeric boundary validation (5 to 100 years).
• Journey Date: Must not be in the past (Date >= Today).
• Card Number: 16 digits with auto-spacing (/^\d{16}$/).
• Seat Selection: Interactive selection with a limit of max 4 seats.

3. DEVELOPMENT: REACTJS SOURCE CODE (App.jsx)

```jsx
import React, { useState } from 'react';

const COUNTRIES = [
  { code: '+91', name: 'India', pattern: /^[6-9]\d{9}$/, len: 10 },
  { code: '+1', name: 'USA', pattern: /^\d{10}$/, len: 10 }
];

export default function App() {
  const [form, setForm] = useState({
    name: '',
    email: '',
    country: '+91',
    phone: '',
    age: '',
    date: new Date().toISOString().split('T')[0],
    seats: ['A1'],
    card: ''
  });

  const [errors, setErrors] = useState({});
  const [submitted, setSubmitted] = useState(false);

  // Client-Side Validator Function
  const validate = () => {
    const errs = {};
    const today = new Date().toISOString().split('T')[0];

    // Name Validation
    if (!form.name.trim()) {
      errs.name = 'Full Name is required.';
    } else if (!/^[A-Za-z\s]{3,40}$/.test(form.name)) {
      errs.name = 'Only letters allowed (3-40 chars).';
    }

    // Email Regex Validation
    if (!form.email.trim()) {
      errs.email = 'Email address is required.';
    } else if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(form.email)) {
      errs.email = 'Enter a valid email format.';
    }

    // International Phone Regex Validation
    const c = COUNTRIES.find(x => x.code === form.country);
    if (!form.phone.trim()) {
      errs.phone = 'Phone number is required.';
    } else if (!c.pattern.test(form.phone)) {
      errs.phone = `Invalid ${c.name} phone (must be ${c.len} digits).`;
    }

    // Age Boundary Validation
    const ageNum = parseInt(form.age, 10);
    if (!form.age) {
      errs.age = 'Age is required.';
    } else if (isNaN(ageNum) || ageNum < 5 || ageNum > 100) {
      errs.age = 'Age must be between 5 and 100.';
    }

    // Date Validation
    if (form.date < today) {
      errs.date = 'Travel date cannot be in the past.';
    }

    // Card Number Validation (16 digits)
    const cleanCard = form.card.replace(/\s+/g, '');
    if (!/^\d{16}$/.test(cleanCard)) {
      errs.card = 'Card number must be exactly 16 digits.';
    }

    return errs;
  };

  const handleSubmit = (e) => {
    e.preventDefault();
    const validationErrors = validate();
    setErrors(validationErrors);
    if (Object.keys(validationErrors).length === 0) {
      setSubmitted(true);
    }
  };

  return (
    <div style={{ maxWidth: 500, margin: '30px auto', fontFamily: 'sans-serif' }}>
      <h2>BusGo — React Client-Side Validation</h2>
      
      {submitted ? (
        <div style={{ background: '#dcfce7', padding: 15, borderRadius: 8, color: '#166534' }}>
          <h3>✓ Validation Passed & Ticket Confirmed!</h3>
          <p>Passenger: {form.name} | Phone: {form.country} {form.phone}</p>
          <button onClick={() => setSubmitted(false)}>Book Another</button>
        </div>
      ) : (
        <form onSubmit={handleSubmit} style={{ display: 'flex', flexDirection: 'column', gap: 12 }}>
          {/* Name */}
          <div>
            <label>Full Name:</label>
            <input
              style={{ width: '100%', padding: 8, borderColor: errors.name ? 'red' : '#ccc' }}
              value={form.name}
              onChange={(e) => setForm({ ...form, name: e.target.value })}
              placeholder="e.g. Vedant Sharma"
            />
            {errors.name && <span style={{ color: 'red', fontSize: 12 }}>{errors.name}</span>}
          </div>

          {/* Email */}
          <div>
            <label>Email Address:</label>
            <input
              style={{ width: '100%', padding: 8, borderColor: errors.email ? 'red' : '#ccc' }}
              value={form.email}
              onChange={(e) => setForm({ ...form, email: e.target.value })}
              placeholder="name@domain.com"
            />
            {errors.email && <span style={{ color: 'red', fontSize: 12 }}>{errors.email}</span>}
          </div>

          {/* Phone with Country Selector */}
          <div>
            <label>Phone Number:</label>
            <div style={{ display: 'flex', gap: 6 }}>
              <select value={form.country} onChange={(e) => setForm({ ...form, country: e.target.value })}>
                {COUNTRIES.map(c => <option key={c.code} value={c.code}>{c.name} ({c.code})</option>)}
              </select>
              <input
                style={{ flex: 1, padding: 8, borderColor: errors.phone ? 'red' : '#ccc' }}
                value={form.phone}
                onChange={(e) => setForm({ ...form, phone: e.target.value.replace(/\D/g, '') })}
                placeholder="9876543210"
              />
            </div>
            {errors.phone && <span style={{ color: 'red', fontSize: 12 }}>{errors.phone}</span>}
          </div>

          {/* Age & Date */}
          <div style={{ display: 'flex', gap: 10 }}>
            <div style={{ flex: 1 }}>
              <label>Age:</label>
              <input
                type="number"
                style={{ width: '100%', padding: 8, borderColor: errors.age ? 'red' : '#ccc' }}
                value={form.age}
                onChange={(e) => setForm({ ...form, age: e.target.value })}
              />
              {errors.age && <span style={{ color: 'red', fontSize: 12 }}>{errors.age}</span>}
            </div>

            <div style={{ flex: 1 }}>
              <label>Journey Date:</label>
              <input
                type="date"
                style={{ width: '100%', padding: 8, borderColor: errors.date ? 'red' : '#ccc' }}
                value={form.date}
                onChange={(e) => setForm({ ...form, date: e.target.value })}
              />
              {errors.date && <span style={{ color: 'red', fontSize: 12 }}>{errors.date}</span>}
            </div>
          </div>

          {/* Payment Card */}
          <div>
            <label>Card Number (16 Digits):</label>
            <input
              style={{ width: '100%', padding: 8, borderColor: errors.card ? 'red' : '#ccc' }}
              value={form.card}
              maxLength={19}
              onChange={(e) => {
                let v = e.target.value.replace(/\D/g, '').substring(0, 16);
                setForm({ ...form, card: v.replace(/(\d{4})(?=\d)/g, '$1 ') });
              }}
              placeholder="4532 8976 1234 5678"
            />
            {errors.card && <span style={{ color: 'red', fontSize: 12 }}>{errors.card}</span>}
          </div>

          <button type="submit" style={{ padding: 10, background: '#4f46e5', color: '#fff', border: 'none', borderRadius: 6, fontWeight: 'bold', cursor: 'pointer' }}>
            Validate & Submit
          </button>
        </form>
      )}
    </div>
  );
}
```

  git push origin main
Step 2: Sign in to Vercel (https://vercel.com) & click "Add New Project".

5. OUTPUT & TEST VERIFICATION
• Empty input fields -> Displays "Field is required" error message.
• "vedant123" in Name -> Fails RegEx; outputs "Only letters allowed".
• "user@domain" in Email -> Fails RegEx; outputs "Enter a valid email format".
• 5-digit Phone -> Fails Regex; outputs "Invalid India phone (must be 10 digits)".
• Past Date -> Fails condition; outputs "Travel date cannot be in the past".
• Valid inputs -> Form submits successfully, renders confirmed E-Ticket with zero server lag.
